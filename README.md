# Keyword AI MVP

A starter Next.js dashboard for an AI keyword research SaaS.

## Run locally
1. Install Node.js 20+ from https://nodejs.org/
2. Open a terminal in this folder.
3. Run: npm install
4. Run: npm run dev
5. Open http://localhost:3000

## Current MVP
- Topic or URL input
- Country/language selectors
- Research loading state
- Keyword opportunity dashboard
- Sample keyword results

## Next build steps

2. Connect Google Ads Keyword Planner or a keyword-data provider for real search volume.
